3 · The three loops — where the experience recycles

The product is intentionally cyclical: a minute-to-minute loop, a day-to-day loop, and an automatic week-to-week loop.

4 · Auth & session — and the re-login fix

Access token = 15 min (in storage); refresh token = 7-day httpOnly cookie. The green path is the fix that stopped "I have to log in every time."

flowchart TD
    Start["App loads"] --> HasTok{"access token
in storage?"}
    HasTok -- yes --> Me["GET /api/auth/me"]
    HasTok -- "no (cold load / new tab)" --> Refresh

    Me --> Ok{"valid?"}
    Ok -- yes --> In["✅ Signed in → render app"]
    Ok -- no --> Refresh["POST /api/auth/refresh
(7-day cookie)"]:::fix

    Refresh --> RefOk{"cookie valid?"}
    RefOk -- yes --> Persist["store new token
in localStorage"]:::fix
    Persist --> Me2["GET /api/auth/me"] --> In
    RefOk -- no --> Out["→ /auth/login"]

    In -. "any 401 later" .-> Refresh

    note["BEFORE THE FIX: 'no token' went
straight to /auth/login — the valid
7-day cookie was never tried."]:::warn
    HasTok -.-> note
